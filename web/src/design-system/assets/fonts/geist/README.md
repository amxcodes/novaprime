# Geist Variable font assets

These normal variable WOFF2 subsets and the `wght.css` face declarations are copied from `@fontsource-variable/geist` 5.3.0. The font is distributed under the SIL Open Font License 1.1; keep the included `LICENSE` with these assets.

`wght.css` is imported by the design-system foundation. Vite resolves its relative font URLs into content-hashed same-origin assets for the configured deployment host or CDN.
